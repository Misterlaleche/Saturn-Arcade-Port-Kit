# Mazinger Z — Sega Saturn Level 1 Demo R01

One-player Sega Saturn prototype targeting NTSC/60 Hz with left/right movement only.

## Level
Intermediate robots -> Doublas M2 mid-boss -> more intermediate robots -> Garada K7 final boss.

## Controls
- Left/Right: move
- A: punch
- B: heavy attack
- C: Rocket Punch
- X: Breast Fire
- Y: Rust Hurricane
- Start: restart

R01 uses original procedural 4bpp prototype sprites generated at boot; no ripped commercial game assets are included.

Build with Yaul:

    make -j2
