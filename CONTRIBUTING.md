# Contributing

Keep this repository reusable and legally clean.

## Accepted

- Saturn renderer improvements.
- VDP1/VDP2 helpers.
- Input, camera, animation, DMA and VRAM-management improvements.
- Generic extraction/conversion tooling.
- Synthetic or freely redistributable test data.
- Documentation of hardware behaviour.

## Do not commit

- Commercial ROMs.
- Extracted copyrighted graphics, music or voice samples.
- Game-specific distributable disc images containing copyrighted assets.
- Proprietary SDK material.

When adding code derived from another open-source project, preserve its licence and attribution requirements.
